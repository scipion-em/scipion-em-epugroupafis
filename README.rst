===================================
Scipion plugin for EPU_group_AFIS
===================================

This plugin runs `EPU_group_AFIS <https://github.com/DustinMorado/EPU_group_AFIS>`_
inside Scipion 3. The program groups movies acquired with EPU AFIS into RELION
optics groups from their XML metadata.

Installation
------------

Install the plugin in development mode from a Scipion installation::

    scipion3 installp -p /path/to/scipion-em-epugroupafis --devel

Then install ``epugroupafis-git`` from Scipion's plugin manager. This creates a
dedicated Conda environment and installs the current upstream Git version.

Protocols
---------

* **Generate AFIS groups from movies** creates the original EPU_group_AFIS STAR
  file and a second STAR file accepted by RELION's **Assign optics groups**
  protocol.

Input staging
-------------

The protocol accepts either a flat XML directory or the unmodified root of an
EPU session, such as ``...DATA_X``. It searches all subdirectories recursively,
matches each input movie to its ``FoilHole_*_Data_*.xml`` metadata file, and
creates a flat staging directory inside the protocol working directory using
symbolic links. The source movies and XML files are not copied or modified.

When some files cannot be paired, Scipion displays a confirmation warning before
execution with the total number of movies, XML files, matched pairs, unmatched
movies, and unmatched XML files. If execution continues, only matched pairs are
processed. The protocol stops only when processing is not possible, for example
when there are no matched pairs or fewer matched pairs than requested optics
groups.

MTF selection and outputs
-------------------------

The MTF STAR file can be entered as a path or selected with the wizard from
RELION's predefined MTF files. The protocol produces:

* ``outputStar``: the original STAR file generated by EPU_group_AFIS.
* ``outputRelionStar``: a STAR file whose ``data_micrographs`` table is
  compatible with RELION's **Assign optics groups** protocol.
